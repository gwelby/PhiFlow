What is PhiFlow?

PhiFlow compiles .phi source programs through a typed intermediate representation into executable quantum circuits, OpenQASM 3.0 output, and a sensor-aware runtime — all from a language designed around intention, observation, and coherence rather than registers and branches.

Execution on a real IBM Heron r2 processor (ibm_fez) has been verified.

The Language

PhiFlow has six first-class constructs. Everything else is ordinary programming.

intention
Declares a named scope of purposeful computation. Coherence is tracked within it.
stream
A concurrent sub-scope. Breaks when it hits break stream.
witness
Pauses execution, samples coherence, and records a checkpoint.
resonate
Broadcasts a value into the resonance field — visible to other intentions.
coherence
Returns the current phi-harmonic coherence score (0.0–1.0).
anchor
Gates execution on physical sensor thresholds before proceeding.

Minimal Program

intention "find_ground" {
    stream "approach" {
        let signal = 76.0
        while signal < 431.9 {
            let diff = 432.0 - signal
            signal = signal + (diff * 0.382)
        }
        resonate signal
        witness signal
        break stream
    }
}

Architecture

PhiFlow compiles through four layers, each independently verifiable:

  • Parser — Handles 0.4.0 constructs + imports
  • PhiIR + Lowering — Typed intermediate representation, String-backed
  • Evaluator / VM — Unified runtime via String-backed IR
  • Codegen — WASM (table-proxy strings) + OpenQASM 3.0 (Heron-ISA verified)

Three-backend equivalence is sacred: Evaluator == VM == WASM.
