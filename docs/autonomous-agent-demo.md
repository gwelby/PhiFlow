# The Autonomous Agent Demo: Why the Five Primitives Matter

## The Question

PhiFlow has five language primitives — `intention`, `witness`, `coherence`, `resonate`, and `stream` — that have no direct equivalent in conventional programming languages. The natural question is: **so what? What can you do with these that you can't do with a regular language?**

The answer is not "nothing" — you can implement equivalent behavior in any Turing-complete language. The answer is: **the primitives make self-observation a first-class language feature, not a library concern.** This changes how programs are written, not what they can compute.

`examples/autonomous_agent.phi` is a concrete demonstration of this difference.

## The Program

The agent program (`examples/autonomous_agent.phi`) is an autonomous data analysis agent. It:

1. Declares its intention: "I am analyzing data"
2. Loops through data readings in a self-defining stream
3. Reads its own coherence at each step
4. Checkpoints its state (witness) at each step
5. Shares significant findings to the resonance field
6. Stops when data confidence is high (success)
7. Stops when its own coherence drops below safe limits (emergency)
8. Stops when it hits a hard cycle limit (timeout)

The program is 80 lines of PhiFlow. It uses all five primitives for their stated purpose. It runs in the evaluator, the browser demo, and (with caveats about the WASM host's coherence tracking) the WASM backend.

## The Key Distinction

The program makes a distinction that is central to PhiFlow's design:

- **CONFIDENCE** is the agent's assessment of the DATA (external)
- **COHERENCE** is the agent's assessment of ITSELF (internal)

These are two different things. A traditional program tracks confidence (data quality) but has no built-in notion of coherence (self-alignment). In PhiFlow, both are first-class:

```phi
let conf = confidence(reading, cycle)   // external assessment
let current_coherence = coherence        // internal assessment
```

The agent uses confidence to decide "is the data good enough?" and coherence to decide "am I still operating safely?" These are different questions with different answers.

## The Three Stopping Conditions

The agent has three reasons to stop, each demonstrating a different primitive:

### 1. Success (data confidence ≥ threshold)

```phi
if conf >= confidence_threshold {
    witness conf
    resonate conf
    break stream
}
```

The agent has processed enough data to be confident in its analysis. It witnesses the confidence value (checkpoint), resonates it (share to the field), and breaks the stream. This is the normal success path.

### 2. Emergency (coherence ≤ safety floor)

```phi
if current_coherence <= safety_floor {
    witness current_coherence
    break stream
}
```

The agent's own coherence has dropped below a safe level. This is the **language-level guardrail** — the agent detects its own degradation and stops. No external monitor tells it to stop. It reads its own alignment state and makes the decision itself.

This is the primitive that matters most for autonomous AI safety. An agent that can detect when it is no longer "aligned" (in PhiFlow's terms: when its coherence has dropped) and stop itself is safer than one that requires an external monitor to detect the same condition.

### 3. Timeout (cycle ≥ max)

```phi
if cycle >= max_cycles {
    witness current_coherence
    break stream
}
```

The hard safety brake. If neither success nor emergency triggers, the agent stops after a fixed number of cycles. This is the same as a timeout in any language — but in PhiFlow, it's the third line of defense, not the first.

## The Audit Trail

When the agent runs, it produces three streams of evidence:

1. **Intention stack:** "data_analysis" — the agent's declared purpose
2. **Witness log:** A checkpoint at every cycle, showing the agent's coherence at each decision point
3. **Resonance field:** The significant findings the agent chose to share

This audit trail is not added after the fact. It is generated by the language primitives as the program runs. A reviewer (human or automated) can inspect:
- What the agent was trying to do (intention)
- What it observed about itself at each step (witness log)
- What it shared with the outside world (resonance field)
- Why it stopped (the final witness event)

In a conventional language, producing this audit trail would require explicit logging code — `log.info("cycle {}", cycle)`, `log.info("coherence {}", coherence)`, etc. In PhiFlow, the primitives generate it as a side effect of normal execution.

## What This Demonstrates

The demo shows that PhiFlow's primitives are not theoretical constructs. They are practical tools for building autonomous systems that:

1. **Declare their purpose** before acting (`intention`)
2. **Monitor their own state** continuously (`coherence`)
3. **Checkpoint their decisions** for auditability (`witness`)
4. **Share significant findings** with observers (`resonate`)
5. **Run until they decide to stop** based on their own assessment (`stream` + `break`)

The program is small (80 lines) but honest. It doesn't claim to be a production agent. It claims to demonstrate that the five primitives work together to give an autonomous agent language-level access to its own operational state.

## What This Does Not Demonstrate

- **Not a production agent:** The data readings are simulated. A real agent would read from sensors, APIs, or databases.
- **Not a consciousness proof:** The agent's coherence is a mathematical function of its execution depth and resonance count, not a measure of consciousness.
- **Not a safety guarantee:** The coherence-based emergency stop is only as good as the coherence formula's ability to capture "alignment degradation." Whether the formula captures this in a meaningful way is an empirical question.
- **Not unique to PhiFlow:** All of this behavior could be implemented in Python, Rust, or any other language. The claim is not that PhiFlow enables new computations. The claim is that PhiFlow makes self-observation a language-level concern, which changes how programs are structured.

## Running the Demo

```bash
# Evaluator (full output)
cargo run --bin phic -- examples/autonomous_agent.phi

# With metrics
cargo run --bin phic -- --measure examples/autonomous_agent.phi

# Browser demo (zero install)
# Open examples/browser/index.html and select "autonomous_agent.phi"
```

The evaluator output shows the agent running 10 cycles, resonating 6 significant findings (confidence > 0.8), and stopping when confidence reaches 0.909 (≥ 0.90 threshold). The final coherence is 0.608 — the agent stopped via the success path, not the emergency or timeout path.
