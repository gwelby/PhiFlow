# PhiFlow Gold Receipt Pilot
*Buyer-safe draft for T-005*

## What This Is

PhiFlow is a research-grade compiler/runtime for self-observing programs. It lets a team describe a workflow with constructs such as `witness`, `coherence`, `resonate`, and `handoff`, then produce auditable runtime artifacts and, where appropriate, OpenQASM output for quantum workflow verification.

This pilot is not a SaaS subscription and not a medical or therapeutic product. It is a fixed-scope research engagement that produces one reproducible artifact chain.

## Best Fit

This pilot is for teams that already work with one of these areas:

1. quantum software, OpenQASM, Qiskit, or IBM Quantum workflows,
2. adaptive or human-in-the-loop experiments,
3. multi-agent systems that need signed handoff evidence,
4. sensor-conditioned research protocols.

## Pilot Outcome

By the end of the pilot, the buyer receives a "Gold Receipt" package:

1. one buyer-specific `.phi` workflow,
2. compiler/runtime output and reproduction notes,
3. OpenQASM artifact if the workflow includes a quantum path,
4. simulator results and an IBM hardware attempt where access permits,
5. test/conformance notes for the delivered workflow,
6. known limitations and next-step recommendations.

## Scope

Included:

1. one discovery session to select the workflow,
2. one small `.phi` implementation,
3. one verification pass against the current PhiFlow gate,
4. one artifact/receipt report,
5. one handoff session explaining how to reproduce the result.

Not included:

1. guaranteed quantum advantage,
2. production deployment,
3. clinical, medical, or therapeutic validation,
4. security certification,
5. browser productization,
6. custom hardware procurement.
