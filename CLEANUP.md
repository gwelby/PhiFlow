# PhiFlow Project History: The Cleanup Era

## Overview
The `PhiFlow-cleanup` branch (and worktree) represents an earlier architectural era of the project, primarily focused on Python and CUDA-accelerated simulations.

## Context
Before the current Rust-based PhiIR and PhiVM architecture was established (v0.2.0+), the project utilized:
- **Python**: For research, early parser implementations, and visualization.
- **CUDA**: For high-performance consciousness-coherence calculations on NVIDIA hardware.
- **Legacy IR**: A stack-based interpreter logic.

## Status
- **State**: Archived.
- **Purpose**: Reference for original algorithms and CUDA memory management patterns. 
- **Action**: This branch is no longer used for active development. New features are implemented in `master` using the Rust compiler stack.
