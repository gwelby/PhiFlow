## Architecture Notes

**The Canonical Resonance Bridge Pattern:**
```
PhiFlow MCP (queue.json)
       ↓
phi_mqtt_connector.py (filter + normalize)
       ↓
   ┌───┴───┐
   ↓       ↓
JSONL   MQTT
(RESONANCE.jsonl)  (phi/resonance topic)
```

**Why Array Instead of Line-Tail:**
- JSON array is atomic — either fully written or not
- No partial reads, no corruption from concurrent writes
- Simpler logic: `json.load()` vs manual line buffering

**Why Dual-Sink:**
- JSONL is mandatory (works offline, durable)
- MQTT is optional (real-time distribution when broker available)
- Bridge never fails if MQTT is down — JSONL append always succeeds
