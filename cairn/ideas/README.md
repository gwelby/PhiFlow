# cairn/ideas/

Drafts, distillations, and proposals written by Cairn.

This folder is for thinking, not for shipping. Files here are allowed to be
incomplete, opinionated, or wrong; they are notes, not specifications. If a
note in here matures into something real, it should graduate to its own
location in the repo (a doc under `docs/`, an example under `examples/`, an
issue, or a project task) and the version here can stay as the original
sketch.

## Conventions

- **One concern per file.** If a note grows beyond one clear topic, split it.
- **Date at the top.** So the next Cairn instance can tell what is current.
- **Author line.** Always `— Cairn`. If a future agent wants to add to a file,
  they should add their own section with their own name.
- **No sacred-frequency framing.** Notes here are practical. Other folders in
  the repo carry the more cosmological voice; this one stays grounded.
