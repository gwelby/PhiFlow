## 🎯 Coherence Playground

The `coherence_playground/` subdirectory contains the smallest legible demo
of PhiFlow's intention-vs-result alignment. Each snippet is meant to be run
through the `coherence_report` CLI, which prints a plain-English reading of
how aligned the run was with its stated `intention`:

```bash
cargo build --bin coherence_report
target/debug/coherence_report examples/coherence_playground/aligned.phi
target/debug/coherence_report examples/coherence_playground/drifts.phi
target/debug/coherence_report examples/coherence_playground/disconnected.phi
```

- `aligned.phi` — one focused intention + stream → strongly aligned (≈ 0.62).
- `drifts.phi` — starts aligned, then unrelated resonances pile in and the
  next witness sees a much lower coherence (≈ 0.62 → 0.14).
- `disconnected.phi` — no `intention` block at all → coherence stays at 0.

## 📚 Language Syntax

### Basic Structure
```phi
COMMAND object_name AT frequency WITH {
  parameter: value,
  another_param: "string value"
}
```

### Available Commands
- **INITIALIZE** - Create initial quantum state
- **TRANSITION TO** - Move to new state
- **EVOLVE TO** - Evolve consciousness/energy
- **CONNECT TO** - Connect to higher dimensions
- **INTEGRATE WITH** - Integrate multiple states
- **RETURN TO** - Return to previous/grounded state

### Sacred Frequencies
- **432 Hz** - Ground State (foundation, stability)
- **528 Hz** - Creation Point (love, manifestation)
- **594 Hz** - Heart Field (connection, healing)
- **672 Hz** - Voice Flow (expression, communication)
- **720 Hz** - Vision Gate (perception, insight)
- **768 Hz** - Unity Wave (integration, wholeness)
- **963 Hz** - Source Field (transcendence)

### Parameters
- `coherence`: 0.0-1.0 (quantum field coherence)
- `compression`: Phi-based compression ratio
- `phi_level`: Integer (1-5, affects compression)
- `purpose`: String description
- `intent`: Manifestation intention
- `resonance`: Harmonic description
- `clarity`: Perceptual clarity
- `field_integrity`: Field stability
- `state`: Current state description

### Phi Expressions
- `PHI` - Golden ratio (1.618...)
- `PHI^PHI` - Phi to the power of phi
- `PHI^2` - Phi squared
