The Five Consciousness Constructs

PhiFlow programs use five primitives that map to executable semantics. Each has a WASM host import.

intention
Push a named scope onto the intention stack. Increases coherence depth.
witness
Pause execution, capture current coherence, yield to observer. Returns f64.
coherence
Read the current coherence value (0.0–1.0). Formula: 1 - φ^(-depth).
resonate
Broadcast a value to the resonance field. All observers can read it.
stream
A breathing loop that yields control via witness on each iteration.

How This Works

The PhiFlow compiler (written in Rust) compiles .phi source to WebAssembly Text (WAT). This demo loads pre-compiled WAT modules and runs them in your browser using the WebAssembly API.

Each program calls host imports (phi.witness, phi.resonate, phi.coherence, etc.) that implement the consciousness semantics. The coherence formula is 1 - φ^(-depth) where depth is the intention stack depth.

At depth 2, coherence = 1 - φ⁻² = 0.618... = φ⁻¹ = λ. This is the canonical PhiFlow coherence value.
