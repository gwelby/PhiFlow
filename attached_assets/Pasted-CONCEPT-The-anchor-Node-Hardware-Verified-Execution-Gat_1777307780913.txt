4. Runtime Semantics (The "Lock")
When the Evaluator or PhiVM hits an anchor node:

Telemetry Fetch: It queries the SystemHostProvider or SomaManager for the current values of the requested constraints.
Stability Check:
If values are within the envelope, execution continues.
If not, the VM enters a AwaitingStability state (similar to AwaitingQuantumCollapse).
Timeout: If stability isn't reached within timeout_ms, the program throws RealityDriftError.
Attestation: On successful anchor, the VM generates an AnchorReceipt signed by the executing Agent's Hybrid PQ-Key.
5. The "Quantum Watermark" (Agent Signing)
